# A2 feature parity matrix

This is the living migration ledger for the approved A2 redesign. It tracks the behavior that already exists in the application separately from its A2 presentation status. A feature is not considered migrated merely because its repository, ViewModel, route, or legacy UI already works.

Status as of 2026-07-22 on `feat/a2-figma-redesign-20260716-095823`:

- **Complete — foundation:** A2 color, type, spacing, shape, motion, adaptive dimensions, and the compatibility theme API are implemented in commit `512c05f`.
- **Implemented in the current worktree — UI migration:** the shared A2 component families, adaptive Mobile/Tablet navigation, TV drawer/focus primitives, Favorites destination, primary content screens, onboarding, settings/security, update host, and Mobile/Tablet/TV player surfaces have been migrated. Remaining certification work is restricted to connected-device behavior, accessibility, and target-resolution visual comparison.
- **Current validation:** `testDebugUnitTest`, `lintDebug`, `assembleDebug`, signed `assembleSelfHostedRelease`, `bundleRelease`, R8, release lint-vital, APK signature verification, and post-edit `git diff --check` pass. The complete unit suite is green. Critical phone and TV flows were exercised on connected emulators: release upgrades preserved the installation data area, both cold starts completed without a fatal exception or ANR, the mobile Movies/Series surfaces rendered, and the TV player Center/Left/Right overlay routes and focus recovery were verified. Broader API-level, accessibility, and target-resolution certification remains tracked in `docs/MANUAL_QA.md`.
- **Existing gap:** behavior or a platform surface is absent, incomplete, latent, or not wired in the current application. These items need an explicit implementation or product decision; a visual restyle alone cannot close them.

The foundation gate passed before screen work began: `:app:compileDebugKotlin`, `lintDebug`, `testDebugUnitTest` (268 tests), `assembleDebug`, and `git diff --check` all passed. Lint then remained at the pre-existing baseline of 167 warnings and one informational finding. The final combined worktree now has fewer lint warnings (154) and no A2-specific lint warning. ## Completion rule

A row can move to complete only when its existing behavior is preserved, its applicable Mobile/Tablet/TV A2 surfaces are implemented, and the listed validation has passed. Final redesign certification additionally requires a clean build gate (`clean`, `lintDebug`, `testDebugUnitTest`, `assembleDebug`, and `git diff --check`), connected tests when a device/emulator is available, and screenshot comparison at 360x800 Mobile, 1280x800 Tablet, and 1920x1080 TV. Any waived or pre-existing issue must be recorded separately; it must not be hidden under an A2 parity claim.
