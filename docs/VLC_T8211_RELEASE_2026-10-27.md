## Release boundaries and remaining work

T8211 remediation is a bounded backport. It does not upgrade the end-of-life Libgcrypt 1.10 branch or certify every statically linked library. The exact native ledger remains open for substantive security/license review of VLC, Jellyfin and the two AndroidX native owners. In particular, complete the linked-library advisory applicability assessment, including retained GnuTLS, and the source/binary correspondence and distribution review. A clean Maven OSV scan cannot replace this work.

Corresponding-source materials must identify this exact `.5` package, retain the application and component sources/notices/build instructions and satisfy the applicable distribution/relinking obligations. A local staging directory is not a published source offer. No repository visibility change, source publication, commit, push or Play upload has occurred.

After these gates close: freeze/review the source revision, run mandatory remote CI for that revision, and use Play internal testing to verify Play-delivered artifacts before production promotion. Passed unrelated tests should not be rerun solely because this note was updated. The earlier `.4` AAB in `build/play-readiness-2026-10-27/artifacts/` predates this security fix and must not be selected for publication.
